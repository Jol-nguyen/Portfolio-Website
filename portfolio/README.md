# Facet portfolio

Open `index.html` in a modern browser. No installation or build step is needed. Upload the three website files (`index.html`, `styles.css`, `script.js`) together to any static website host when ready.

## Make it yours

- Edit the `profile` object at the top of `script.js` for your name, email, location, biography, availability, and skills.
- Edit the three entries in `projects` for your projects, descriptions, skills, and concept details. Set each `url` to an actual HTTPS project address to open your project instead of its sample detail dialog.
- Each project’s `headline`, `brand`, and other mockup fields customize its illustrated preview. Replace `.mock-browser` in `index.html` with your own image if you prefer real screenshots; add meaningful alt text.
- Edit the hero heading and footer copy in `index.html`. Update the meta description there before publishing.
- Theme colors are defined at the beginning of `styles.css`. The geometric hero artwork is an inline SVG, inspired by the supplied reference.

All names, projects, and contact details are placeholders. Example projects are explicitly labeled as concepts; no results or client work are claimed.

## Interaction and accessibility

The carousel supports previous/next buttons, direct slide selectors, left/right arrow keys when focused, and horizontal touch swipes. It never advances automatically. Project dialogs support Escape and return focus to the trigger through the browser’s native dialog behavior. The page includes a skip link, visible keyboard focus, live slide announcements, semantic sections, and reduced-motion support.

Google Fonts is optional and requires an internet connection. Local system font fallbacks keep the site usable offline.
